# Lee's Restaurant Website

A modern Italian restaurant website built with Svelte, featuring a responsive menu, online table booking, photo gallery, and Google Maps integration.

## Features

- **Homepage** with contact information and trading hours
- **Online Table Booking** with calendar and time selection
- **Downloadable Menu** in PDF format
- **Animated Photo Gallery** showcasing menu items
- **Google Maps Integration** for restaurant location
- **Responsive Design** for all devices

## Tech Stack

- **Frontend**: Svelte, HTML5, CSS3, JavaScript
- **Calendar**: HTML5 date input with custom time selection
- **Maps**: Google Maps API
- **Version Control**: Git

## Installation

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## API Keys

Create a `.env` file in the root directory:

```
VITE_GOOGLE_MAPS_API_KEY=your_api_key_here
```
